# 照片墙模块用法

## 默认写法

连续写两张以上图片时，会自动排成类似王导导相册的 mosaic 拼贴墙。图片会 `cover` 填满拼贴块，因此可能有轻微裁剪，但会有更强的错落感。

## 悬停预览

鼠标放到照片墙图片上时，会自动显示较大的浮层预览。触控设备不会触发这个效果，避免挡住正文。

## 不裁剪模式

如果某一组照片必须完整显示，可以手写 `data-layout="masonry"`。这个模式按图片自然比例瀑布流排列，不会裁剪。

<div class="photo-wall" data-layout="masonry">
  <div class="photo-wall__grid">
    <a href="assets/photo-1.jpg"><img src="assets/photo-1.jpg" alt="照片说明"></a>

  </div>
</div>

## 手动指定拼贴尺寸

默认 mosaic 会按图片组数量生成稳定的错落尺寸。想指定某张图放大时，Markdown 里可以在图片说明末尾加尺寸标记，渲染时标记会被自动移除。

![想放大的照片 |2x2](assets/photo-1.jpg)

![横向照片 |2x1](assets/photo-2.jpg)

![竖向照片 |1x2](assets/photo-3.jpg)

可用尺寸包括 `1x1`、`2x1`、`1x2`、`2x2`、`3x1`、`1x3`、`3x2`、`2x3`。如果手写 HTML，也可以继续用 `data-size`。

<div class="photo-wall" data-layout="mosaic">
  <div class="photo-wall__grid">
    <a href="assets/photo-1.jpg" data-size="2x2"><img src="assets/photo-1.jpg" alt="想放大的照片"></a>
    <a href="assets/photo-2.jpg"><img src="assets/photo-2.jpg" alt="照片说明"></a>
    <a href="assets/photo-3.jpg"><img src="assets/photo-3.jpg" alt="照片说明"></a>
  </div>
</div>

## 独立迁移

现在照片墙已经封装成独立产品包，源码和文档在 `packages/photo-wall`。

构建并同步可迁移文件：

```bash
npm run photo-wall:build
```

复制这两个构建产物到其他博客，并在页面中引入：

- `packages/photo-wall/dist/photo-wall.css`
- `packages/photo-wall/dist/photo-wall.js`

仓库里也会同步一份到旧路径，方便继续手动复制：

- `template/photo-wall/photo-wall.css`
- `template/photo-wall/photo-wall.js`

普通站点引入后会自动初始化；如果内容是后加载的，调用 `window.PhotoWall.init()` 重新扫描即可。Quartz 中已经自动接入。
